# Clinical-note extraction — evaluation

The task: turn a free-text consultation note into structured, reviewable data. That means:
- diagnoses as ICD-10 codes;
- medications with their action (started / continued / dose changed / stopped), dose and frequency;
- vitals and labs in canonical units;
- the follow-up interval.

**Everything runs locally.** No external LLM or API is called, so no patient text leaves the server. The extractor is deterministic and free to run (about 5 ms per note).

## The extractor ([`app/nlp/local.py`](../app/nlp/local.py))

It builds on the frozen v1 rules ([`app/nlp/rules.py`](../app/nlp/rules.py)) in three switchable layers:

| Layer | What it does |
|---|---|
| **v1 rules** (baseline, frozen) | Condition and drug lexicons, regex vitals/labs with unit conversion (°F, lb, ft/in, mmol/L), NegEx-style negation scope, verb-scoped medication actions, follow-up intervals |
| **1. Text normalisation** | Spoken-out numbers to digits ("one forty over ninety" → 140/90); clinical and US abbreviations ("O2 sat", "A-fib", "tmrw", "FU 3/12"); common Hinglish ("le rahi hai", "kar diya", "2 hafte baad"); colloquial dose changes ("bumped up", "step down"); **spelling correction** against the drug and condition vocabulary ("metfromin" → metformin) |
| **2. Expanded lexicon** ([`lexicon_ext.py`](../app/nlp/lexicon_ext.py)) | About 55 more conditions, about 200 more generics, about 100 Indian/US brand names, and detection of unknown drug names from the "word + dose + unit" pattern |
| **3. Medication-action classifier** ([`train_action.py`](../app/nlp/train_action.py)) | TF-IDF (word plus character n-grams) with logistic regression over the text around each medication mention. **Ships only if it beats the rules in cross-validation**, and currently it doesn't (see below) |

Evidence quotes always come from the **original** note, not the normalised text, so the review UI can highlight them.

### Spelling correction is conservative by design
A token is corrected only if all of these hold:
- it is 6 or more letters long;
- it shares its first two letters with the target;
- its length is within 2 of the target;
- its similarity to the target is at least 0.8.

On top of that, 131 real English words that sit close to drug or disease names are protected ("allegro", "brilliant", "cleaner" and so on). They're generated by [`build_protected_words.py`](../app/nlp/build_protected_words.py) from a system word list, so the runtime needs no dictionary.

## Data: [`notes.jsonl`](notes.jsonl), 64 synthetic notes

| Split | Notes | Role |
|---|---|---|
| `dev` | 16 | Used while writing the v1 rules |
| `test` | 20 | Scored once with v1 frozen; later used for tuning v2 |
| `stress` | 12 | Written after v1 was frozen (misspellings, Hinglish, dictation, out-of-lexicon drugs); later used for tuning v2 |
| **`holdout`** | **16** | **Written before any v2 work**, never inspected during development, scored once at the end. Integrity checked by `.holdout.sha256` (and a unit test) |

Gold labels allow alternatives where coding is genuinely ambiguous. They also mark "optional" items, which are neither rewarded nor penalised.

**Scoring** ([`app/nlp/evaluate.py`](../app/nlp/evaluate.py)):
- **Conditions:** match on the ICD-10 category.
- **Medications:** generic name, with brands and combination order normalised.
- **Measurements:** (code, value) within max(0.2, 2%).
- **Attributes:** action, dose and frequency accuracy on matched medications.
- **Follow-up:** within 10%.

## Results on the held-out notes (scored once)

| Variant | Precision | Recall | **F1** | Conditions F1 | Medications F1 | Measurements F1 | Med action acc. | Follow-up acc. |
|---|---|---|---|---|---|---|---|---|
| v1 rules (baseline) | 0.98 | 0.62 | **0.76** | 0.42 | 0.78 | 0.88 | 0.81 | 0.75 |
| + text normalisation | 1.00 | 0.68 | **0.81** | 0.57 | 0.79 | 0.96 | 0.88 | 1.00 |
| **+ expanded lexicon (shipped)** | **1.00** | **0.92** | **0.96** | 0.89 | 0.99 | 0.96 | 0.90 | 1.00 |
| + action classifier, hybrid (not shipped) | 1.00 | 0.92 | 0.96 | 0.89 | 0.99 | 0.96 | 0.95 | 1.00 |

On the earlier splits, v1 scored F1 1.00 on dev, 0.99 on test and 0.70 on stress. Those splits were later used to tune v2, so v2's scores on them (≈1.00) aren't evidence of anything.

### What the shipped extractor still gets wrong on the held-out notes
- **Colloquial diagnoses it doesn't know:** "sugar patient" (an Indian colloquialism for diabetes), "known asthmatic", "post CABG" implying coronary disease.
- **Dose changes stated without naming the drug:** "Cut down to 50 mcg", "Evening dose reduced to 10 units".
- **Discharge-medication lists:** "Discharged … on prednisolone" is read as *continued* rather than *started*.
- **Lab abbreviations followed by extra words:** "Hb on discharge 9.6", "Creat 1.1".
- **Odd formatting:** a calcium + vitamin D combination written with doses inside it, and "60,000 IU" (the thousands comma).

### The action classifier: an honest negative result
Leave-one-note-out cross-validation over the 48 tuning notes, run through the full extraction pipeline:

| Mode | Med action accuracy (n=103) |
|---|---|
| Rules only | **0.951** |
| Hybrid (model only where no explicit verb) | 0.922 |
| Model only | 0.854 |

The selection rule picked **rules**, so the classifier ships disabled (`models/action_clf.joblib`, mode `rules`). This comparison even favours the rules, which were tuned on the same notes.

On the holdout, though, the hybrid scored higher (0.95 vs 0.90). That's 2 of 40 medications, so the difference isn't meaningful either way. I didn't switch modes based on the holdout, because that would turn it into a tuning set. The takeaway is that about 100 labelled mentions isn't enough to decide. Retrain with more labelled notes and the classifier ships automatically once it wins in cross-validation:

```bash
.venv/bin/python -m app.nlp.train_action
```

## Caveats
- **Same author.** One developer wrote the notes, the labels and the extractor. The holdout notes were written before any v2 code, but the expanded lexicon was written afterwards. A list of common conditions and drugs naturally overlaps with holdout content, so the vocabulary gains (layer 2) are likely **optimistic**. The normalisation gains (layer 1) are less affected. An independently written and annotated note set is the most important next step.
- **Small data.** 64 synthetic notes; scoring is at ICD-10 category level.
- **Rules have a ceiling.** Free narrative and unseen phrasing will keep producing misses, which is why every result is a draft for clinician review rather than an automatic write.

## Reproduce

```bash
cd apps/api
.venv/bin/python -m app.nlp.evaluate --method local --split holdout --errors
.venv/bin/python -m app.nlp.evaluate --method rules-v1 --split holdout
.venv/bin/python -m app.nlp.train_action          # ~8 min: cross-validation + retrain
```
